# SaaS (Software as a Service)

## What is SaaS?

SaaS provides ready-to-use software over the internet. We only use it and pay for usage. The provider manages everything else — servers, updates, and security.

## Examples:

- Google Drive
- Microsoft 365 (Word, Excel online)
- Gmail

## One sentence to remember:

SaaS is software you use over the internet without managing anything.
