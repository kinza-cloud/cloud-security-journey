# AWS Config

## What is AWS Config?

AWS Config is a service that watches every security setting in the cloud and checks every change that occurs in the AWS account. It gives a message when something changes and shows an immediate response if something goes wrong.

It keeps a record of everything that changes in your AWS account — who changed it, what was changed, and when.

## Why it matters for security:

- If someone changes a Security Group to allow traffic from anywhere, AWS Config detects it.
- If someone deletes a critical resource, AWS Config records it.
- It helps you track compliance with security rules.

## One sentence to remember:

AWS Config watches your cloud resources and alerts you when something changes.
