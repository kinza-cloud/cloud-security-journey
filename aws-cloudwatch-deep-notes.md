# AWS CloudWatch (Deep Dive)

## What is AWS CloudWatch?

AWS CloudWatch monitors your cloud resources and applications. It collects logs, tracks metrics, and sends alerts when something goes wrong.

## Why it matters for security:

- Monitors CPU, memory, and network usage
- Sends alerts when something is wrong
- Helps detect unusual activity
- Logs every event for investigation

## One sentence to remember:

CloudWatch monitors your cloud resources and alerts you when there is a problem.
