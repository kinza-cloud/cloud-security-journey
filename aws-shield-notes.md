# AWS Shield

## What is AWS Shield?

AWS Shield protects against DDoS attacks. DDoS stands for Distributed Denial of Service. In this attack, a hacker tries to crash or stop a website from working by sending a huge amount of fake traffic (requests) to it.

## How it works:

When a request comes to the website, it first goes to AWS Shield. AWS Shield checks the traffic and blocks harmful requests before they reach the website.

## Types:

- **Shield Standard:** Free and included with AWS. Protects against common attacks.
- **Shield Advanced:** Paid service. Offers faster protection, 24/7 support, and financial protection.

## One sentence to remember:

AWS Shield protects your website from DDoS attacks so it stays online.
