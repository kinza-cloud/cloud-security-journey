# AWS KMS (Key Management Service)

## What is AWS KMS?

AWS KMS (Key Management Service) helps you create and manage encryption keys to protect your data in the cloud.

## What is encryption?

Encryption scrambles data so that only authorized people can read it.

## Analogy:

- You have a lock and key → Encryption key
- Only the person with the key can open the lock → Only authorized users can decrypt data
- You keep the key safe → AWS KMS stores and manages keys securely

## Why it matters for security:

- Without KMS, you manage keys yourself (risky)
- With KMS, AWS manages keys securely
- Keys are protected and audited
- You control who can use the keys
## Key Concepts:

| Concept | Meaning |
|---------|---------|
| CMK (Customer Master Key) | The main key used for encryption |
| Data Key | A key generated by KMS to encrypt your data |
| Key Rotation | Changing the key regularly for security |
| Key Policy | Controls who can use the key (like IAM policy) |

## Why Key Policy Matters:

- It defines **who** can use the key
- It controls **what actions** they can perform
- It enforces **least privilege** for encryption keys
## One sentence to remember:

AWS KMS creates and manages encryption keys to protect your data in the cloud.
