# AWS Route 53

## What is AWS Route 53?

AWS Route 53 is a Domain Name System (DNS) service that translates domain names like google.com into IP addresses.

## Why it is useful:

- We don't need to remember IP addresses
- We can remember easy domain names instead
- Helps users reach websites easily

## One sentence to remember:

AWS Route 53 translates domain names (like google.com) into IP addresses.
