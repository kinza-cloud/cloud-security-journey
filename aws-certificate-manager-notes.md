# AWS Certificate Manager (ACM)

## What is AWS Certificate Manager?

AWS Certificate Manager (ACM) is a service that helps you create, manage, and deploy SSL/TLS certificates for your websites and applications.

## What is SSL/TLS?

SSL/TLS certificates encrypt data between users and your website. Without SSL, your website shows "Not Secure". With SSL, your website shows "Secure" (🔒) and data is protected from hackers.

## Why it matters for security:

- Encrypts data between users and your website
- AWS provides free certificates
- Certificates are renewed automatically
- Users trust websites with HTTPS

## One sentence to remember:

AWS Certificate Manager provides free SSL/TLS certificates to encrypt data between users and your website.
