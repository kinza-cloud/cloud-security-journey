# AWS Trusted Advisor – Theory

## What is AWS Trusted Advisor?

AWS Trusted Advisor is a service that gives recommendations to improve your AWS environment. It checks your account and tells you what to fix.

## What Does Trusted Advisor Check?

| Category | What It Checks |
|----------|----------------|
| Security | Open ports, MFA on root, public S3 buckets |
| Cost | Unused resources, idle EC2 instances |
| Performance | Slow resources, high usage |
| Fault Tolerance | Backups, Multi-AZ, redundancy |
| Service Limits | Approaching AWS limits |

## Why is Trusted Advisor Important?

- Gives free security recommendations
- Helps reduce cost
- Improves performance
- Works automatically in your AWS account

## One Sentence to Remember

> AWS Trusted Advisor is like a helpful assistant that tells you how to make your cloud safer and cheaper.
