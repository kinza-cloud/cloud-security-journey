# AWS RDS (Relational Database Service)

## What is AWS RDS?

RDS is a managed cloud database service that handles backups, updates, and scaling for you. You don't need to manage the server yourself.

## Why it is useful:

- Automatic backups keep your data safe
- Scalability – grows with your needs
- Security – encrypts your data
- No server management needed

## One sentence to remember:

RDS is a managed cloud database that handles backups, updates, and scaling for you.
