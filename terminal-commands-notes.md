# Terminal Commands Practice (Windows/Linux)

These are the basic terminal commands I practiced to navigate the file system and manage files.

## Commands Learned:

| Command | What It Does |
|---------|--------------|
| `mkdir <folder_name>` | Creates a new folder (directory). Example: `mkdir cloudpractice` |
| `cd <folder_name>` | Moves inside that folder. Example: `cd cloudpractice` |
| `echo "text" > <file_name>` | Creates a file and writes text inside it. Example: `echo "I am learning cloudfront" > test.txt` |
| `type <file_name>` | Reads and displays the text inside the file (Windows). |
| `cat <file_name>` | Reads and displays the text inside the file (Linux/Mac). |
| `ls` or `dir` | Lists all the files and folders in the current directory. |
| `cd ..` | Moves back one folder (to the parent directory). |

## Why This is Important for Cloud Engineering

As a cloud engineer, you will rarely use a mouse. You will manage servers, create files, and navigate through the system using the terminal. Practicing these commands builds muscle memory for working with Linux servers (like EC2 instances) in the cloud.

## One Sentence to Remember

> The terminal is the cloud engineer's workspace; mastering `cd`, `mkdir`, and `echo` is the first step to managing servers.
