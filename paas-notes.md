# PaaS (Platform as a Service)

## What is PaaS?

PaaS provides a platform to build and run applications without managing servers. We write the code and manage the data, but the servers, operating system, and updates are managed by the provider.

## Examples:

- AWS Elastic Beanstalk
- Google App Engine

## One sentence to remember:

PaaS lets you build apps without worrying about the underlying servers.
