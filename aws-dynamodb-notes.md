# AWS DynamoDB

## What is DynamoDB?

DynamoDB is a fast, flexible, serverless NoSQL database in the cloud. It stores data in tables without a fixed structure.

## Key Features:

- Serverless – No servers to manage
- Fast – Very low latency
- Scalable – Handles large amounts of data
- Flexible – No fixed structure

## One sentence to remember:

DynamoDB is a fast, flexible, serverless NoSQL database in the cloud.
