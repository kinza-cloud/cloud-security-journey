# Encryption

Encryption is like a secret code. It scrambles our data.

## How it works:
- Only the right person can read it
- If someone steals the data during transmission, they cannot read it because it's in a secret code

## Why it matters:
Encryption keeps our data secure, both when stored (at rest) and when traveling (in transit).

## Example:
Sending a secret message to a friend. The message is in a code. Only your friend can decode it.

## One sentence to remember
Encryption scrambles data so only authorized people can read it.
