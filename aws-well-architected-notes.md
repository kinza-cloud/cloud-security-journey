# AWS Well-Architected Framework

## What is it?

AWS Well-Architected Framework is a set of best practices to build secure and reliable cloud applications.

## The 6 Pillars:

1. **Operational Excellence** – Run and monitor your systems well
2. **Security** – Protect your data and systems
3. **Reliability** – Keep your systems running
4. **Performance Efficiency** – Use resources wisely
5. **Cost Optimization** – Save money
6. **Sustainability** – Protect the environment

## One sentence to remember:

AWS Well-Architected Framework helps you build secure and reliable cloud applications.
