# AWS Lambda

## What is AWS Lambda?

AWS Lambda is a cloud service that runs code only when needed. You pay only for the time your code runs. If you do not use it, you do not pay.

## Analogy

A light turns on when someone enters a room. You pay the electricity bill only when the light is on. When the light is off, you pay nothing.

## One sentence to remember

Lambda runs your code only when needed, without servers, and you pay only for what you use.
