# AWS CloudFormation

## What is AWS CloudFormation?

AWS CloudFormation is a service that helps you create and manage AWS resources using templates (code files). Instead of clicking buttons to create resources, you write a template and CloudFormation creates everything for you automatically.

## Analogy:

- You give a recipe to a chef → You give a template to CloudFormation
- The chef follows the recipe → CloudFormation creates the resources
- You get the same dish every time → You get the same setup every time

## Why it is useful:

- Saves time (no manual clicking)
- Consistent setup every time
- Easy to recreate resources

## One sentence to remember:

AWS CloudFormation uses templates to create and manage AWS resources automatically.
