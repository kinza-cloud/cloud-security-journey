# AWS GuardDuty

## What is AWS GuardDuty?

AWS GuardDuty is a threat detection service that continuously monitors your AWS account for suspicious activity. It uses machine learning to find threats like hackers, malware, or unusual behavior.

## What does it detect?

- Unusual login attempts from strange locations
- Malware or harmful software
- Unauthorized access to resources
- Abnormal data traffic (could mean data theft)

## How it works:

1. GuardDuty monitors your AWS account continuously
2. If it finds something suspicious, it creates an alert
3. The alert is sent to CloudWatch and Security Hub (if enabled)
4. You can investigate and take action

## One sentence to remember:

AWS GuardDuty is like a security camera that watches your AWS account and alerts you when something suspicious happens.
