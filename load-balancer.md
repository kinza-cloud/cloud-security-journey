# Load Balancer

A Load Balancer sends requests to servers that have fewer requests. If one server is overloaded or fails, other servers keep working.

## Analogy:
It is like having many stores in different cities. When there is a rush, customers are sent to the stores that are less busy. Work gets done faster and better.

## One sentence to remember
A Load Balancer spreads traffic across multiple servers so no single server gets overwhelmed.
