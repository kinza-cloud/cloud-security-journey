## What is EC2?

EC2 is a virtual computer in the cloud. We can turn it on and off based on our need. We only pay for the resources we use and for the time we use it.

## How to launch EC2:

1. Choose AMI (operating system - like software for the computer)
2. Choose Instance Type (hardware - how powerful the computer is)
3. Configure Instance (adjust settings)
4. Add Storage (add hard drive space as needed)
5. Add Tags (labels like "My Server")
6. Configure Security Group (firewall - who can enter, who cannot)
7. Review and check all work is complete
8. Launch (submit)
