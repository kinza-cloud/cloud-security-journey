# AWS Inspector

## What is AWS Inspector?

AWS Inspector is a service that scans cloud resources like EC2 servers. First, we install an agent on the EC2 server. Then Inspector scans the server and finds vulnerabilities and weaknesses in our systems. It tells us how dangerous the issue is and what action is needed.

## Why it matters:

Without Inspector, we would not be able to find these vulnerabilities in our systems.

## One sentence to remember:

AWS Inspector scans your cloud servers for vulnerabilities and tells you what to fix.
