# AWS Organizations

## What is AWS Organizations?

AWS Organizations is a service that manages multiple AWS accounts from one central place. We don't need to apply policies or security rules to each account separately. We apply them at one place, and they apply to all accounts.

## Benefits:

- One combined bill for all accounts
- Easy to manage security rules
- Save time and effort

## One sentence to remember:

AWS Organizations lets you manage multiple AWS accounts from one central place.
