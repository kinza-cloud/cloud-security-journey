# AWS IAM Identity Center – Theory

## What is AWS IAM Identity Center?

AWS IAM Identity Center (formerly AWS SSO) lets users log in once and access multiple AWS accounts and applications. It is a single place to manage access.

## What Does It Do?

| Function | What It Means |
|----------|---------------|
| Single Sign-On | One login for all accounts |
| Centralized access | Manage users in one place |
| Works with Organizations | Applies to all accounts |
| Supports MFA | Extra security |

## Why is IAM Identity Center Important?

- Simplifies access management
- Reduces password fatigue
- Improves security with MFA
- Works with external identity providers (like Google, Microsoft)

## One Sentence to Remember

> IAM Identity Center lets users log in once and access everything they need — safely.
