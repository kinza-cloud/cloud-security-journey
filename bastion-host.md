# Bastion Host

A Bastion Host allows you to access a private subnet from the internet.

## Analogy:
It is like a security guard that has the key to a locked room. The guard opens the lock and we can access it.

## How it works:
- Bastion Host has a public IP address
- You connect using port 22 (SSH)
- It then connects you to the private subnet

## One sentence to remember
A Bastion Host is a secure gateway to access private subnets from the internet.
