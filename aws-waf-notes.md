# AWS WAF (Web Application Firewall)

## What is AWS WAF?

AWS WAF checks and protects our website from hacker attacks. Requests first go to AWS WAF, and it checks them. If a request will create a problem for the website, WAF blocks it. If the request is safe, WAF allows it.

## Types of attacks AWS WAF protects against:

- **SQL Injection:** Hacker tries to steal database data.
- **Cross-Site Scripting (XSS):** Hacker tries to put wrong code on the website.
- **DDoS Attack:** Hacker sends too many requests to the website so it stops working.
- **Bad Bots:** Fake programs trying to enter the website.

## One sentence to remember:

AWS WAF is a firewall that protects your website from hackers and bad traffic.
