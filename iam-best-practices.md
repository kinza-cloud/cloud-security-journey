# IAM Best Practices

## Rule 1: Least Privilege

Give users only the permissions they need. Nothing more.

**Example:** If a user only needs to read files, do not give them write or delete permissions.

## Rule 2: Use Groups

Put users in groups. Give permissions to the group, not to each user.

**Example:** "Developers" group can read and write. "Viewers" group can only read.

## Rule 3: Use Strong Passwords

Require long, complex passwords. Never share passwords.

## Rule 4: Enable MFA (Multi-Factor Authentication)

Require a second verification method (like a code from your phone) for important accounts.

## Rule 5: Review Permissions Regularly

Remove permissions that users no longer need.

## One sentence to remember:

Give the least access needed, use groups, enable MFA, and review permissions regularly.
