# AWS EC2 (Deep Dive)

## What is EC2?

EC2 is a virtual cloud server that we use and pay only for the time we use it.

## Key Features:

- AMI (Amazon Machine Image) – Template for your server
- Security Groups – Firewall rules
- Elastic IP – Fixed public IP address
- Key Pairs – Secure connection to your server

## Pricing Models:

- On-Demand: Pay only when you use it
- Reserved: Pay upfront for discount (1-3 years)
- Spot: Cheaper but can be interrupted

## One sentence to remember:

EC2 is a virtual server in the cloud that you can use on-demand.
