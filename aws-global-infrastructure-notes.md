# AWS Global Infrastructure

## What is AWS Global Infrastructure?

AWS has data centers all over the world. These are divided into Regions (geographical areas like Europe, Asia Pacific). AWS also has Edge Locations near users to reduce latency and provide faster access.

## Benefits:

- Low latency – faster access for users
- High availability – if one region fails, another works
- Disaster recovery – data is safe in multiple locations

## One sentence to remember:

AWS has regions, availability zones, and edge locations to keep services fast and reliable.
