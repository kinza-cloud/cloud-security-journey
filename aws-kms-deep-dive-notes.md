# AWS KMS – Deep Dive Notes

## What is AWS KMS?

AWS KMS (Key Management Service) creates and manages encryption keys to protect your data in the cloud.

## Key Concepts

| Concept | Meaning |
|---------|---------|
| CMK (Customer Master Key) | The main key used for encryption — never leaves KMS |
| Data Key | A temporary key generated by KMS to encrypt your data |
| Key Policy | Controls who can use the key (like IAM policy) |
| Key Rotation | Changing the key regularly for security |

## How It Works

1. You ask KMS to encrypt your data
2. KMS uses a CMK to generate a Data Key
3. The Data Key encrypts your data
4. The Data Key is encrypted by the CMK
5. Only users with permission can decrypt

## Why Key Rotation Matters

- Limits the damage if a key is leaked
- Meets compliance requirements
- Best practice for cloud security

## One Sentence to Remember

> AWS KMS manages encryption keys — CMKs are the main keys, Data Keys do the work, and Key Policies control access.
