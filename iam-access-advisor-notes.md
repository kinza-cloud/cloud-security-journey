# IAM Access Advisor – Theory

## What is IAM Access Advisor?

IAM Access Advisor is a tool in AWS that shows which AWS services a user or role has accessed, and when they last used them.

## How Does It Help Enforce Least Privilege?

Access Advisor shows unused permissions. If a user has not used a service for a long time, we can safely remove that permission. This helps enforce the principle of least privilege.

## Why Is It Useful for Cloud Security?

- It identifies unused permissions
- It reduces unnecessary access
- It lowers the risk of attacks
- It helps keep the AWS account clean and secure
- It supports auditing and compliance

## What Does It Show?

- Which services a user or role has accessed
- When each service was last used
- Which permissions have never been used

## One Sentence to Remember

> IAM Access Advisor shows which permissions are actually being used — so you can remove the ones that are not.
