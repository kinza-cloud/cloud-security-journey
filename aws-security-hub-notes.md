# AWS Security Hub

## What is AWS Security Hub?

AWS Security Hub is a central dashboard where all your security alerts from different AWS services come together in one place.

## What it does:

- Collects alerts from GuardDuty, Inspector, Macie, and other services
- Shows a security score (like a grade for your cloud)
- Checks if you are following security best practices

## Analogy:

AWS Security Hub is like a control room where all security cameras and alarms are displayed. GuardDuty sends an alert → Security Hub shows it. Inspector finds a vulnerability → Security Hub shows it. Macie finds sensitive data → Security Hub shows it.

## One sentence to remember:

AWS Security Hub is a central dashboard that collects and displays all your cloud security alerts.
