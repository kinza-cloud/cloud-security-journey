# IP Address

IP address is the address on each device where the internet connects to the device.

There are two types of IP address:
- Public IP address
- Private IP address

Public IP address is given by the internet company to each house. Each house has its own public IP address.

Private IP address is the address that is different on each device. Each device has its own private IP address.

The router identifies that address on each device and the internet connects to that device.
