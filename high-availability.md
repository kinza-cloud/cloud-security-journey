# High Availability (HA)

High Availability means if one server goes down, another server is present. Our data moves to that server.

## Why it matters:
- Users do not notice any problem
- Our app stays working
- Our reputation stays good

## Without HA:
- If a hacker attacks one server, the app goes down
- Users are affected
- Reputation is damaged

## One sentence to remember
High Availability means using multiple servers so that if one fails, others keep working.
