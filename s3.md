# S3 (Simple Storage Service)

S3 is a storage service in the cloud.

## What it does:
- Store files, photos, videos, and backups in the cloud
- You control who can access, change, or delete your data
- Has backup system so if data is deleted, you can restore it
- Data is properly protected

## Example:
Like uploading photos from your mobile to the cloud.

## One sentence to remember
S3 is cloud storage where you control access, backup, and security of your files.
## Deep Dive Points:

- S3 has **Versioning** – keeps multiple versions of a file
- S3 has **Encryption** – protects your files
- S3 has **Access Control** – who can view, upload, or delete
## S3 Security – Why It Matters

- By default, all S3 buckets are **PRIVATE**
- Only the owner (or users with permission) can access files
- If a bucket is made **PUBLIC**, anyone on the internet can see your files

### Security Risks of Public Buckets:
- Personal data (photos, videos, documents) can be exposed
- Hackers can steal or delete your data
- Companies get fined for exposing customer data

### Best Practices for S3 Security:
- Keep buckets **PRIVATE** unless absolutely necessary
- Use **Bucket Policies** to control access
- Enable **Encryption** to protect data at rest
- Enable **Versioning** to recover deleted files
- Use **MFA Delete** for extra protection

### One Sentence to Remember:
> *"An S3 bucket should be private by default — only give access when needed."*
