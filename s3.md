# S3 (Simple Storage Service)

S3 is a storage service in the cloud.

## What it does:
- Store files, photos, videos, and backups in the cloud
- You control who can access, change, or delete your data
- Has backup system so if data is deleted, you can restore it
- Data is properly protected

## Example:
Like uploading photos from your mobile to the cloud.

## One sentence to remember
S3 is cloud storage where you control access, backup, and security of your files.
